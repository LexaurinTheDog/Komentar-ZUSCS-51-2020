# Komentář k zákonu č. 51/2020 Sb., o územně správním členění státu a o změně souvisejících zákonů (zákon o územně správním členění státu)

Otevřený komentář k zákonu o územně správním členění státu — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; správní obvody krajů a obcí s rozšířenou působností, vymezení okresů, obvody hlavního města Prahy, výkon působnosti některých obcí, zmocnění, novely a zrušovací ustanovení.

Konsolidované znění: dokument e-Sbírky `SB-2020-00051_2021-01-01`.
